# 极速海岸 Coast Rush

> 🌊 阳光海岸开放世界 · 极品飞车风自由驾驶网页游戏

**线上地址：https://yjj0339.github.io/coast-rush/**

## 玩法
- 🏎️ 中置引擎超级跑车，6 种车漆随时换（C 键）
- 🗺️ 2.6km × 2.6km 开放世界：市中心高楼群、滨海公路、南岭山路、灯塔观景台、湖畔、沙滩
- 🌲 全地形自由驾驶：柏油 / 砂石路肩 / 草地 / 沙滩抓地力各不同，随便越野
- 🚀 氮气系统：漂移积攒氮气，Shift 释放尾焰冲刺
- 🚕 20+ AI 车流 + 路边停车，漂移拉烟、胎痕、计分弹幕、碰撞音效全套
- ☀️ 明亮正午光照：物理天空 + 环境反射 + 实时软阴影 + 体积雾 + Bloom
- 📱 手机触屏适配（虚拟按键自动出现）

## 操作
| 按键 | 功能 |
|---|---|
| W / S | 油门 / 刹车·倒车 |
| A / D | 转向 |
| 空格 | 手刹漂移（漂移回充氮气） |
| Shift | 氮气加速（漂移积攒，尾焰+速度线） |
| R | 复位到最近道路 |
| V | 切换视角（追踪/远景/引擎盖） |
| C | 换车漆 |
| M | 声音开关 |
| Q | 画质（高/中/低） |

## 技术
Three.js r16x + Blender 5.2 全程序化建模（GLB），地形高度公式 Python/JS 双实现自动校验，PIL 程序化贴图，WebAudio 合成音效，零第三方运行时依赖（vendor 内置）。
